# DevFlow 🚀

> AI-powered developer productivity and project management platform built to learn and demonstrate full-stack MERN development.

## 🎯 Project Goal

DevFlow is a full-stack application for managing software projects, tasks, notes, team activity, and developer workflows.

This project is being built as a hands-on learning journey with AI-assisted development. The goal is not only to build the application, but to understand how the frontend, backend, APIs, authentication, database, and deployment work together.

## 🧱 Planned Stack

- **Frontend:** React
- **Backend:** Node.js + Express.js
- **Database:** MongoDB + Mongoose
- **Authentication:** JWT + password hashing
- **API:** REST
- **Testing:** Unit/API testing
- **DevOps:** GitHub Actions, Docker, deployment
- **AI:** AI-assisted project features (later milestone)

## ✨ Planned Features

- User registration and login
- Protected routes and authentication
- Project creation and management
- Task management and Kanban workflow
- Task assignment and comments
- Notes and developer resources
- Dashboard and project analytics
- Notifications and activity feed
- Role-based access control
- Search, filtering, and pagination
- AI-powered project assistance
- GitHub integration
- Testing and CI/CD

## 🧠 Learning Approach

We are following:

**Build → Understand → Test → Break → Debug → Improve → Repeat**

AI may generate code, but every major implementation will be studied so the architecture and debugging process are understandable.

## 🗂️ Development Process

GitHub is part of the development process from Day 1.

- Issues are used to track work and learning goals.
- Feature branches are used for meaningful changes.
- Pull requests are used to review changes.
- Commits are kept focused and descriptive.
- GitHub Actions will be introduced as the project becomes production-ready.
